# Theme icons setup

Icons are from [https://selfh.st/icons/](https://selfh.st/icons/).

The WhatsApp launcher uses `scalable/apps/whatsapp.svg`, sourced from [selfh.st](https://github.com/selfhst/icons/blob/main/svg/whatsapp.svg). Dotbot also links this file into `~/.local/share/icons/hicolor/scalable/apps/` so launchers can resolve `Icon=whatsapp` through the standard fallback theme.
