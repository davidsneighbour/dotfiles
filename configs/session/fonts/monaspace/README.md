# Monaspace Argon

Monaspace Argon is used as the code and data typeface for the dotfiles desktop system.

Only the normal-width Argon files needed now are retained:

* `static/MonaspaceArgon-Regular.otf`
* `static/MonaspaceArgon-Italic.otf`
* `static/MonaspaceArgon-Bold.otf`
* `static/MonaspaceArgon-BoldItalic.otf`
* `frozen/MonaspaceArgonFrozen-Regular.ttf`
* `frozen/MonaspaceArgonFrozen-Italic.ttf`
* `frozen/MonaspaceArgonFrozen-Bold.ttf`
* `frozen/MonaspaceArgonFrozen-BoldItalic.ttf`
* `nerdfonts/MonaspiceArNerdFont-Regular.otf`
* `nerdfonts/MonaspiceArNerdFontMono-Regular.otf`

The original Monaspace license is kept in `LICENSE.txt`. The Nerd Fonts Argon files use the `MonaspiceAr` family name because Nerd Fonts cannot use the upstream reserved `Monaspace` name for patched builds.
