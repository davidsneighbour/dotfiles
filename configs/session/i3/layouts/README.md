# Workspace layouts

Saved i3 workspace layouts, one `<label-slug>.json` file for each layout. `configs/session/i3/workspaces/layouts.py` writes, reads, and deletes these files. The key bindings are `Ctrl+Super+S` (save), `L` (load), `D` (delete), and `E` (edit).

The files are tracked in git. A saved file contains window titles and working directories, so check a file before you commit it.

For the file format and limits, see "Workspace layouts" in [`../README.md`](../README.md).
