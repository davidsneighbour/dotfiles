# Dynamic workspace launchers

Before adding or changing a dynamic workspace launcher, its `.desktop` entry, or its Rofi or i3 trigger, read [the dynamic workspace procedure](../../references/dynamic-workspace-launcher.md). For keybindings, also read [the i3 keybinding instructions](i3-keybindings.instructions.md). Read `SESSION.md` first and update it when behaviour changes.
